## 新功能

- **卡片可以放得更低**：侧边栏设置新增“卡片垂直位置”，整列卡片的中心可以在侧边栏上下的 30%–70% 之间移动。默认 50%，与 macOS 一致；调大后卡片离任务栏和手更近。舞台窗口列表出现或消失时卡片通常不动，只在被列表挡住时才下移。
- **设置 → 关于显示最新版本**：本地版本和 GitHub 上的最新版本并排显示，有新版本时那一行带红点。

## 改进

- **检查更新不再受接口限额影响**：改为读仓库 `main` 上的 `.version` 文件，不再走 `api.github.com`（它对同一 IP 每小时只给 60 次），局域网里多台机器同时用也不会查不到更新。
- **CI 每次 push 都核对版本号**：`.version` 与 `mygo.json` 的版本不一致时构建直接失败，避免应用提示的版本和安装包对不上。

## New

- **The cards can sit lower**: Settings → Strip has a new "card position" slider that moves the middle of the cards between 30% and 70% of the way down the strip. 50%, the default, is where macOS puts them; higher values bring them nearer the taskbar and your hand. The cards usually stay put as the list of the stage's windows comes and goes, moving down only when the list would cover them.
- **Settings → About shows the latest version**: the local version and the newest one on GitHub side by side, with a red dot on that row when a newer one is out.

## Improved

- **Update checks no longer hit an API limit**: they read the `.version` file on `main` instead of going through `api.github.com`, which allows one IP only 60 requests an hour, so several machines behind one address no longer miss updates.
- **CI checks the version on every push**: a `.version` that disagrees with `mygo.json` fails the build, so the version the app reports cannot drift from the installers.
