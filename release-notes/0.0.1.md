## StageBar 0.0.1

The first public preview of StageBar, a macOS Stage Manager-inspired live window switcher for Windows.

StageBar 0.0.1 includes stable DWM live previews, Fixed and Floating modes, configurable card layout, mouse-wheel navigation, live settings, multi-monitor support, application icon badges, tray controls, and a self-contained Windows x64 installer.

> The installer is not code-signed yet. Windows SmartScreen may display an unknown publisher warning.

---

## StageBar 0.0.1 中文说明

StageBar 的首个公开预览版本。它是一个受 macOS 台前调度启发、适用于 Windows 的实时窗口切换工具。

0.0.1 版本包含稳定的 DWM 实时预览、固定与悬浮模式、可配置卡片布局、滚轮切换、实时设置、多显示器支持、应用图标、托盘控制，以及自包含的 Windows x64 安装程序。

> 当前安装包尚未代码签名，Windows SmartScreen 可能显示“未知发布者”提示。
